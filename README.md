### 📂 Project Architecture

```plaintext
ajay-s-portfolio/
│
├── Home/           # Hero section scripts and styling
├── About/          # Profile info and skill cards
├── Project/        # Showcase items, cards, and demos
├── Feedback/       # Contact forms and user reviews
├── index.html      # Main entry point
└── README.md       # Project documentation
```
### 1.Quick Start

Clone the repository: 
``` 
git clone https://github.com/ajayxuns/ajay-s-portfolio.git
```
### 2.Navigate to the directory:
```
cd ajay-s-portfolio
```
### 3.Open the project:
